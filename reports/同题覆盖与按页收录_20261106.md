# 同题覆盖 + 按页收录（2026-11-06）

用户的三点要求，逐条对应实现：

1. 「重新生成时如果判定是同一题，后者直接覆盖原来的 JSON，原 JSON 不要了」
2. 「正式交付是什么意思？我们复核好以后，直接把服务器电脑上生成好的 json 文件夹打包给甲方，
   为什么要全部页面放行才生成？」
3. 「客户端工作台为什么要有『看这题 JSON』按钮？直接在审核网站看不就行了」

第 3 条结论：**不做**。审核网站已有「实时题单 / 预览内容」，工作台只负责标注与出框，
不重复一套只读视图，也就不用发客户端更新包。

---

## 一、同一道题只留一条样本

### 原来错在哪

sample id 由**内容指纹**（题干 + 选项 + 答案）派发。所以：

- 把答案从 `42` 改成 `43` → 指纹变了 → 被当成新题，发一个新 id；
- 旧 id 那条错数据继续留在身份库里，旧版本目录里那份 JSON 也还在；
- 打包时两版一起带走，同一道题在包里出现两次。

### 现在的判据

身份库拆成两张表：

| 表 | 键 | 回答什么 |
|---|---|---|
| `questions` | `<教材>#<题目持久 id>` | 这是不是同一道题 |
| `samples` | 内容 sha256 | 这段内容有没有在别的书里交付过（甲方备注2 / H3⑩） |

`_DeliveryIdentity.claim()` 一次事务内给出五种结果：

- `kept` 同题同内容 → 原 id；
- `updated` 同题、内容改过 → 原 id，**旧指纹一并删除**（旧 JSON 作废）；
- `reused` 同书同内容的历史样本（升级前的老库没有题目身份）→ 用它原来的 id，
  这样升级后第一次重出不会换 id；
- `new` 新题 → 发新号；
- `conflict` 同内容已在别的书交付 → 按备注 2 拒收。

**谁点的生成都一样**：同一本书的生成走 `book_locks` 串行，跨进程由 sqlite
`BEGIN IMMEDIATE`（60 秒超时）兜住，后台的实时题单与正式生成共用同一本身份库。

### 版本目录

新版本发布成功后删除同书旧版本目录（`PAPERFLOW_DELIVERY_VERSION_KEEP`，默认 1 = 只留最新）。
历史仍可从 `versions/index.json` 与审核库追溯，冻结工程能按 submission 重出。
版本下拉框只列目录还在的版本，避免点进去报不存在。

## 二、按页收录：不必等整本审完

### 原来的门禁

`decide_page` 里只要还有一页 pending，整本就是 `in_review`；`generate_delivery` 与
`_queue_delivery_job` 各自再查一遍 `status='reviewed'`。审核员审到一半想看真实 JSON，
没有任何入口。

### 现在的规则

- 只要有 **一页** 放行就能生成；
- 只收录「题干页和答案页都放行」的题，其余写进 `quality_report.json` 的
  `reason_summary`（`该题所在页面尚未审核放行`），不静默丢；
- 版本标 `partial`，带 `approved_pages / total_pages`（写进 `generation.json`、
  `current.json`，列表接口给 `delivery_partial`）；
- 列表上 `awaiting_review` 的行直接给「生成已放行部分」，已生成过半本的行给
  「重新生成（含新放行页）」；
- 整本放行仍自动入队一次完整版（`retry=True`，能覆盖已生成的半本）；如果生成过程中
  剩下的页刚好放完，任务会自动再补一次，不会停在半本。

### 一个坑：页号不能混

`review_pages` 里同一物理页的「题目页」和「答案页」各占一行，`page_index` **各自从 0 编号**。
第一版按行数算总页数，结果任何书都被判成「只放行了一半」，生成完立刻又自动重入队。
现在键是 `(kind, page_index)`，页数按 `page_index` 去重，放行要求该页所有行都 approved。

## 三、打包说明

交付包是人工拷给甲方的，同一本书目录里既有交付版本、又有实时题单草稿，直接压整个目录会把
草稿一起带走。所以每次生成都在书目录写一份 `打包说明.txt`：

```
打包给甲方时只带这三样：
  versions/<版本>/k12_dataset/dataset.jsonl
  versions/<版本>/k12_dataset/images/
  versions/<版本>/k12_dataset/quality_report.json
不要打包：ready_samples/（草稿）、versions/index.json（内部索引）
```
