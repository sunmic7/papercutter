# 切题策略层（P2-2）：把散落的 profile 分支收成一张表

日期：2026-10-19
范围：`layout_strategy.py`（新增）、`cut_questions_v4.py`、`paperflow_annotation_api.py`、Electron `js/main.js`、`tests/test_layout_strategy.py`、`tests/test_smart_cutter.py`

## 一、为什么要做

`profile`（版式）在切题流程里决定十几件“要不要特殊处理”的事，但判断写法是散落的字面量：

```python
header_ratio = 0.28 if profile == 'exam' else 0.13
if profile in {'olympiad', 'workbook', 'drill'} and title:      # 第X练
if profile != 'exam': return ''
allow_lesson=profile in {'workbook', 'general', 'instructional'}
```

重构前共 **17 处**，分布在结构 OCR、页分类、分卷、大题切分、答案解析五个环节。带来的问题：

1. 改一条规则要满文件搜 `profile ==`，`holiday` 一个版式就出现在 6 个地方，容易漏改。
2. 回答不了“把版式改成试卷，到底改变了什么”——界面只能显示一个中文名。
3. 想给某个版式单独试一条新规则（比如圈号编号）时，没有统一的插手点。

## 二、做法

新增根目录 `layout_strategy.py`：

- `LayoutStrategy`：`@dataclass(frozen=True)`，18 个开关，默认值 = 通用版式。
- `STRATEGIES`：7 个版式各一份常量（`EXAM` / `HOLIDAY` / `OLYMPIAD` …）。
- `strategy_for(profile)`：**唯一入口**。未知/空值回退 `general`，与旧版 `==` 判断的行为一致。
- `describe()` / `describe_profile()`：返回中文条目，界面直接用。
- `with_overrides(**kw)`：派生改过个别开关的策略，为将来的单页覆盖留口子。

`cut_questions_v4.py` 只把条件换成 `layout_strategy.strategy_for(profile).xxx`，**不传策略对象**——函数签名一个没改，调用方零改动，回归面因此可控。

## 三、等价性怎么证明的

重构最容易出的错是“条件抄错”，光跑几页看不出来。用了两道证明：

**1. 静态映射测试（7 个版式 × 17 个开关 = 119 组）**

`tests/test_layout_strategy.py::StrategyEquivalenceTests` 把每个字段与重构前的字面量并排放：

```python
'practice_title_boundary': lambda p: p in {'olympiad', 'workbook', 'drill'},
'answer_lesson_context':   lambda p: p in {'workbook', 'general', 'instructional'},
```

逐版式断言两者相等。这条测试不依赖 OCR、不依赖抽到哪页，改错条件会立刻红。重构之后**新增**的 `circled_major_numbers` 没有“旧字面量”可对照，单独在 `NEW_FIELDS` 里排除，另用内容测试锁。

**2. 21 页同集合严格 diff**

先用**重构前**的代码跑一遍 `reports/audit_baseline.jsonl` 里的 21 页，落盘 `reports/strategy_before.jsonl`；重构后再跑一遍得 `reports/strategy_after.jsonl`；用新增的 `_experiments/diff_audit.py` 逐字段比对（只忽略 `seconds`/`split_seconds`/`timing` 三个计时字段，`blocks` 里的标题、题号、坐标全部参与）：

```
对比页数 21（仅一侧有的页：无）
完全一致 21 页 / 有差异 0 页
```

覆盖版式：exam 9、drill 3、holiday 3、general 3、workbook 3。加完圈号规则后又复跑一次，仍是 0 处差异（该规则只在 olympiad 生效）。

## 四、顺手补上的真实缺口：奥数书的 ①②③ 编号

21 页集合里没有 olympiad，所以先补了两页冒烟（`_experiments/strategy_smoke.py`），结果发现：

| 页 | 版式 | 结果 |
|---|---|---|
| 小学奥数专题突破一年级 `image0000387A` | olympiad | 1 块「整页」，栏目提级没触发 |
| 教材解读一年级上册 `Scan_...0007` | instructional | 1 块「整页」，但 `classify_page` 从 `question` 变成 `instruction` ✓ |

奥数那页切不开，查下去不是策略层的问题：**这本书根本不用“一、二、三”，整道练习用 ①②③ 编号**。

```
[20] ③指出下图中哪两条线相交…  ④一张正方形的纸，沿直线剪一刀。
[30] ①把动物按两只脚的、四只脚的和会游泳的分类。
```

`extract_major_idx` 只认中文大题号，于是整页塌成一块。新增 `circled_major_numbers` 开关（仅 olympiad）和 `find_circled_number_boundaries()`，规则刻意保守：

- 圈号必须在**行首**，题干至少 4 个字（过滤“②”这种图注、选项标记）；
- 左缘在栏宽的 22% 以内（右侧栏另算）；
- 与已有边界 y 差 ≤35px 时让位；
- `idx = 5000 + 圈号`，与中文大题（1~99）、栏目（2000~2299）、知识点（3000+）都不重叠。

同书等间隔抽 11 页，**5 页从 1 块变成 2~4 块**：

| 页 | 通用 → 奥数 | 切出的块 |
|---|---|---|
| 20 | 1 → 2 | ③ / ④ |
| 48 | 1 → 2 | ③ / ④ |
| 76 | 2 → 3 | ① / ④ / 余下 |
| 90 | 1 → 4 | ① / ② / ③ / ④ |
| 104 | 1 → 2 | 前段 / ③ |

其余 6 页维持 1 块——那一页确实没有圈号练习（纯例题或图）。这是设计预期：宁可少切，不误切。

## 五、界面上能看见“版式改变了什么”

`/api/project/*` 响应新增 `book_profile_notes`：每个版式实际启用的中文条目。教材信息对话框里显示在版式下拉框下方，切换即刷新：

> 页眉标题带按页高 28% 采样；整页参与结构识别（多栏卷不丢中栏）；“大试卷”卷名且无题号判为封面页；卷名漏读时用“卷面书写+第一大题”认卷首；答案页不把“第X讲”当讲次标题

通用版式显示“不套用专用规则，按通用版式处理。”——这句话现在有保证：`GENERAL.describe()` 返回空列表，由单测锁住。

桥版本号 `book-profile-20261019` → `layout-strategy-20261019`，Electron 与桥服务两处已同步。

## 七、下一步

- **圈号规则的边界情况**：同一本书里若圈号用于小题（外层另有题干），会把一道题切成多块。需要再抽 2~3 本奥数书验证，或加“圈号必须处于栏首且前一行是空白”的约束。
- **横排小问**（`56260570` 的 1./2./3. 并排）要按 x 递归切，会新增 `horizontal_minor_cut` 开关，先只在确认过的版式打开，用 `with_overrides` 做单页 A/B。
- 半块被命名成「整页」的问题（页 76 末尾、页 104 开头）：只在局部裁切时出现，属于既有命名习惯，可以单独收敛成“前段内容”。
