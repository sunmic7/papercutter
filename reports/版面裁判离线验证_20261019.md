日期：2026-10-19
范围：`F:\2008-2015\2012\金版卷王名师面对面大试卷数学四年级下册北师大版`（44 张对开扫描，每张 = 2 个书页）

**可以接，但要按"只在可疑页介入 + 结果落盘缓存"的方式接。**

- 抽样 15 页：**改善 2 页 / 持平 7 页 / 不适用 6 页 / 回退 0 页**

- 两处被修掉的具体问题：第 5 张扫描（书页 1–2）右侧四个大题（三、四、五、六）此前被并成 2 个"整页"块，现在各自独立；第 9 张扫描的第三个"空栏"（4257–4901，实际无内容）被识破并丢弃
- 代价：每页首次 4.2～4.6 秒、进程常驻内存约 +650MB；落盘缓存后重复运行 <0.1 秒

## 1. 要解决的问题（第 5 张扫描，书页 1–2）

该页是左右两个书页的对开扫描（4897×3377，宽高比 1.45），左右各是**单栏**页面。

改造前的分栏结果：

```
0-2703 | 2703-4098 | 4098-4897      → 3 个"阅读区"
一、卷面书写   ← column_1
二、想一想     ← column_1
整页           ← column_2  （吞掉 三、四、五、六）
整页           ← column_3
```

第二道栏缝 4098（页宽 83.7%）是假的：右页判断题的"（ ）"括号与最右侧答案列
在版面模型眼里是一条持续存在的窄白带，但它两侧的正文量严重失衡（右侧只有
533px 宽的标记列），并不是阅读栏。

改造后：

```
0-2434 | 2434-4897                  → 2 个阅读区（= 两张物理页）
一、卷面书写 / 二、想一想           ← 左页
三、判断 / 四、选择 / 五、填数 / 六、计算  ← 右页，各自独立
```

对照图：`reports/版面裁判对照_第5页.png`（左红=改造前的整页块，右绿=改造后的六个大题块）

## 2. 裁判怎么判（不依赖文字内容）

模型输出的是**版面区域框**（text / table / image / paragraph_title …）。把这些框
栅格化成占用图后，只用两个几何判据：

| 判据 | 含义 | 阈值 |
|---|---|---|
| 列占用率 | 某条竖直带上"被正文区域框覆盖的正文高度比例"。真栏缝接近 0；栏内段落间距只会在所有 x 上同时低头，不会形成局部凹陷 | ≤ 8% |
| 两侧配比 | 栏缝左右都必须有成片正文，较窄一侧的正文面积占比不能太小 | ≥ 28%，每侧 ≥3 个区域框 |
| 栏缝宽度 | 太宽的多半是"页尾留白" | ≤ 14% 页宽 |
| 单栏最小宽度 | 防止把一条标记列当成一栏 | ≥ 18% |

第 5 页假栏缝 4098 正是被"两侧配比"挡掉的；真栏缝 2434 的三方交叉验证：
版面裁判 2434 / 全页 OCR 空档 2434 / 图像装订缝 2444。

## 4. 全本 44 页栏位一致性

不依赖 OCR，直接对比"版面裁判栏数"与"图像装订缝检测（`_visual_column_split`）"：

| 判据 | 页数 |
|---|---:|
| 一致（裁判 2 栏且栏缝落在装订缝 ±4% 页宽内） | 43 |
| 裁判少分（图像有缝、裁判判单栏） | 1（第 4 页：版权页 + 目录） |
| 裁判多分（裁判多栏、图像无缝） | 0 |

裁判栏数分布：1 栏 6 页（封面/目录/答案封底）、2 栏 35 页、3 栏 1 页（第 28 页）、4 栏 2 页（第 41、42 页答案页，每页两栏）。

第 4 页的"少分"由生产代码里的**对开页兜底**覆盖：裁判判单栏 + 页宽高比 ≥1.24 时，按
`_visual_column_split`（该页给出 2260）二分，不会把整页当一栏。

| 项 | 实测 |
|---|---|
| 单页推理（首次） | 4.2～4.6 秒（CPU，4897×3377） |

## 7. 风险与未做的事

1. **只验证到"大题块"这一层**。小题框精度由后续 `split_major_into_minors` 决定，本次没有逐题人工核验，也没有建立真值集。
2. **内存 +650MB**。Electron 桥进程若同时持有 v5/v6 OCR 引擎，常驻会到 2GB 量级，需要在长跑时观察。
3. **判单栏的 4 个页面依赖兜底**。若将来把裁判升级成"唯一裁决者"（不经兜底），第 4 页这类页面会把整页当一栏，因此**不能**直接去掉兜底。
4. **样本单一**。只用了这一本四年级数学（44 页）。这套阈值（28%/8%/14%）在其他版式（讲义式侧栏、三栏密排）上的表现未验证。
5. 未做：千问语义裁判（P3）、`--profile` 命令行参数（P1/P2）、真值集与指标闭环（P4）。
