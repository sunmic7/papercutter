## 0. 一句话结论

**一条样本 = 一个「答题单元」：页面上一处印刷编号所辖的最小可独立作答、可独立判对错的区域。**

这个"最小"由**最内层编号**决定，不由版面留白决定。**版面空隙只有在它正好落在两个同层编号之间时才允许被当作切线**；落在同一编号辖区内部的空隙（两列口算算式之间 20~60px 的列间隙、竖式框与框之间），一律不得切。

**三步判定顺序（v1.1 定死）**：① **D7 拦截**（纯算式行/选项行先剔除，不许被当成编号）→ ② **B 系列**定编号归属（哪一行是编号、属于哪个作用域）→ ③ **V 系列**判竖切许可（这一列是不是一道独立的题）。顺序不可换。

本案（`_shot_br.png`）判错的原因经实测确认**不是竖切**（本页竖切路径未触发），而是 `2.7+0.2=` 这类**算式行被提升成了编号**（违反 D7），把「1. 直接写得数」和「2. 用竖式计算」各劈成两段。规则化的表达见 §1.2 的 D7-a/b/c 与 §9 的 F-1。

## 1. 交付粒度：什么算一条样本

### 1.1 术语与编号层级

| 层级 | 代号 | 典型形态 | 是否独立成样本 |
|---|---|---|---|
| 一级大题 | L1 | `一、填空。` `六、计算。（30分）` `练习三` | **否**（写入 `major_title` / `context`） |
| 二级小题 | L2 | `1.` `2.` `3.` | **是** |
| 三级小问 | L3 | `(1)` `（2)` `①` `②` | **是**（父级按 §1.2 D2 处理） |
| 例题 | EX | `例3-1` `【例1】` `例题` | **是**（独立编号作用域） |
| 非编号标记 | — | `A. B. C. D.`、`（ ）`、`3.5`、`P12`、`第1题` | **不得作边界** |

**编号作用域**：一个 L1 标题开启一个新作用域，作用域内 L2 从 1 递增；`练习/做一做/举一反三/巩固练习/例题` 也开启新作用域（编号重新从 1 起算）。作用域是 `number_path` 去重与答案配对的第一键（`match_scope_id`）。

### 1.2 粒度决策列表（自上而下，第一条命中即定，不再往下看）

| # | 判定条件（全部满足才命中） | 结论 |
|---|---|---|
| **D1** | 作用域内存在**最内层**编号序列，且序列连续（步长 1；允许跨栏/跨页重新从 1 开始） | 每个最内层编号 = **1 条样本**；该层编号写 `minor_number`（若是 L3 则写 `subsection_number`，`minor_number` 继承父级） |
| **D2** | 某编号行与其第一个子编号行之间存在「父层自带内容区 P」 | 见 §1.3 的 P 区判据：P 是**材料/题面**→ 父级生成 1 条 `region_role=group` 记录；P 是**指令**→ 父级不生成样本，文本进 `subsection_title` + 子样本 `context` |
| **D3** | 作用域内**无** L2/L3 编号，只有 L1 大题标题 | 整个大题块 = **1 条样本**；`minor_number=''`，`number_path=[major_number]` |
| **D4** | 无任何编号（含封面、纯图页、未编号练习） | 块 = **1 条样本**；`minor_number_inferred=true`、`boundary_source='whole_block'`；**若块内 ≥3 行文本且 ≥2 处独立作答位**（括号/横线/算式三选二）→ 追加 `L2: unnumbered_multi_answerable` |
| **D5** | 命中例题体系（`例N` / `例N-M` / `【例N】`） | 例题正文 = **1 条样本**，`subsection_number='例N'`、`region_role='question'`；其后的`练习/做一做/举一反三`**另起作用域**，编号从 1 重算，**禁止并入例题样本**（题中题） |
| **D6** | 圈号 `①②③` 位于**行首**且其后题干 ≥4 个汉字 | 每个圈号 = **1 条样本**（`minor_number` 取圈号数字）；不满足则视为选项/图注标记，**不产生边界** |
| **D7** | 任意位置出现 `A.`~`D.`、`（ ）`、小数（`3.5`）、页码、`第N题`（题内引用） | **禁止**作为样本边界或编号 |
| **D8** | 本条样本的编号来自推断而非直读（`minor_number_inferred=true`） | 可以产出，但**必须进 L2 人工队列**，未复核不得进交付 |

#### D7 的子条款（拦截级；作用于"编号识别"环节，不是粒度决策环节）

D7 在 v1.0 只写了禁令。v1.1 补上**可执行的判定**，否则禁令落不到代码上——工程侧实测表明，本案页 `minor_extra ≠ 0` 的唯一来源就是"算式行被提升为编号"。

| # | 规则 | 判定（可实现） | 正 / 反例 |
|---|---|---|---|
| **D7-a** | **纯算式行不得作编号候选**（含 suspects 救援通道） | 候选行归一化后（去空格、全角→半角、`−`→`-`、`×`→`*`、`÷`→`/`），**同时**满足：① 全文匹配 `^[\d.()+\-*/=]+$`（只由数字、运算符、括号、小数点、等号构成）；② 含至少一个运算符（`+ - * /`）或等号 `=`。**含任何汉字或字母的行一律不拒绝。** | 拒绝：`2.7+0.2=`、`3.08+6.32=`、`4.75×0.98`、`10.01×0.11`、`17+0.33=`。保留：`2.0.42的计数单位是（ ）`、`1.5路公共汽车…`、`3. 下面各题…`（含汉字）、`1. 2+3=5 的算式对吗？`（含汉字，**不得误拒**） |
| **D7-b** | rescue 通道的准入条件 | `N.` 之后首字符为汉字/字母 → 允许登记为疑似编号；`N.` 之后首字符为数字 → **必须**通过 D7-a 才允许登记 | — |
| **D7-c** | **D7 拦截必须先于"正好补上序列空缺"的采纳逻辑** | 拦截在"登记 suspects"处完成，不得在 merge/采纳阶段才过滤 | 本案实测：merge 时 `2` 紧跟 `1` 被采纳 → 若在采纳阶段过滤已太晚，边界序列已被污染 |

> 结论：**D7-a 落地后，本案页的确认编号序列恢复为 `[1(直接写得数), 2(用竖式计算)]`，切出数 = 印刷数 = 2，`minor_extra` 归零，且不需要新增任何字段或机制。**

### 1.3 D2 的 P 区判据（消除"视情况而定"）

取父级编号行下沿到第一个子编号行上沿之间的垂直区间 P：

- 记 `P_text` = 落在 P 内的 OCR 文本，`P_h` = P 的高度，`line_h` = 该块中位行高，`slots(P)` = P 内作答位数量（`（ ）`/`____`/`=` 结尾算式/答题空白框）。
- **判为指令**（不生成记录）：`P_h < 2.5 × line_h` **且** `slots(P) == 0` **且** `P_text` 命中指令词表（`计算|直接写得数|用竖式计算|解方程|填空|判断|选择|回答问题|画一画|连一连|列式计算|口算`）**且** `P_text` 长度 ≤ 20 字。
- **判为材料/题面**（生成 `group` 记录）：不满足"指令"三条中的任一条，即 `P_h ≥ 2.5×line_h` **或** `slots(P) ≥ 1` **或** `P_text` 不含指令词且长度 > 20 字。
- 典型结果：`1. 直接写得数。（6分）` → P_h≈1 行、无作答位、命中"直接写得数" → **指令**，不单独成记录（本案）；`阅读下面短文，完成练习。`+整段材料+`(1)(2)(3)` → P_h 远大于 2.5 行 → **材料**，生成 `group` 记录。

| 印刷编号形态 | 实例 | 层级 | 样本粒度 | 起点锚点 | 终点锚点 |
|---|---|---|---|---|---|

## 2. 切分边界

### 2.1 纵向锚点（B 系列）

| # | 规则 |
|---|---|
| **B1** | `y_start(i=0)` = 大题块块顶（`0`）。首题必须把大题标题**像素**一起带上，避免"标题块"这种空壳。 |
| **B2** | `y_start(i>0)` = `y(本编号行上沿) − max(4, 0.5×行高)`；若该值小于上一条样本的 `y_end`，取上一条 `y_end`（样本不得重叠）。 |
| **B3** | `y_end(i)` = `min(下一同级编号上沿 − 4, _find_clean_horizontal_cut 空白带中线)`；末题 = 块高。 |
| **B4** | **空白带不存在时不得落刀到内容行内**：若 `[y_start(i+1)−36, y_start(i+1))` 内没有 ≥3px 高的低密度带，则 `y_end = y(下一编号上沿) − 2`，并置 `cut_quality='tight'`（可用，但计入诊断）。 |
| **B5** | 判断题括号、填空横线、算式结果位**不得跨切**：切线上方 1 个行高内若存在 `（` 未闭合、`____` 未结束、`=` 后无内容，切点下移到该元素闭合行之下。 |
| **B6** | 带图题：图示（示意图/统计图/几何图）的整个连通区域必须落在**同一条**样本 `bbox` 内。若图的纵向范围跨过 `y_end`，`y_end` 上移到图的底部（宁可本条样本变高，不许把图切开）。 |

### 2.2 横向范围：什么时候可以竖切（V 系列，本案核心）

**默认不竖切。** 竖切是例外，必须逐条满足 V-ALLOW，且不得命中任一 V-DENY。

**V-ALLOW（5 条全部满足才允许竖切）**

| # | 条件（可判定） |
|---|---|
| V-A | 栏缝来自**页面级独立视觉证据**：`layout_arbiter` 给出的 `_column_bounds`，或 `_visual_column_split` 找到的连续纯留白（≥60% 页高）/**实线**；**不得**仅凭局部 OCR 左缘聚类的空隙（`_side_by_side_columns` 当前的聚类结果不算证据）。 |
| V-B | 每条候选列在其**列顶 25% 高度内**存在自己的编号行（`V-B1`：编号上沿 ≤ 列顶 + 0.25×列高），且该编号左缘 ≤ 列宽 × 28%（`V-B2`：列内确实是"题首"）。 |
| V-C | 各列编号是**不同编号且连续**（左列最大号 +1 = 右列最小号），即"并排的三道独立小题"；编号相同或缺失的列 = 同一题的内容。 |
| V-D | 切线不与任何**闭合矩形框**（竖式框、作答框、表格线）相交。判据：切线与检测到的矩形竖直边交点数 = 0，且矩形左右边分居切线两侧时矩形横跨切线 → 拒绝。 |
| V-E | 正文区内**没有横跨切线的文本行**（行宽 ≥ 列宽 45% 且两侧各越线 ≥18px 的行数 = 0，与 `has_spanning_body_text` 同口径）。 |

**V-DENY（命中任一即禁止竖切，且不因 V-ALLOW 满足而豁免）**

| # | 条件 | 对应真实形态 |
|---|---|---|
| **V-DENY(i)** | 切线某一侧**没有编号行**，而另一侧有 —— 该侧是同一小题的正文（并排算式/选项/竖式），不是独立小题 | **本案**：右列 6 个算式没有编号，被当成一列切开 |
| **V-DENY(ii)** | 切线上下各 1 个行高内不存在编号行 —— 刀落在同一答题单元内部 | 竖式计算 3 个框之间、口算 4 行之间 |
| **V-DENY(iii)** | 缝隙宽度 < `max(1×行高, 页宽 × 3%)` 且两侧文本块宽度均 < 列宽 × 45% —— 这是"算式组/选项组的列间隙"，不是栏缝 | 两列口算（列间隙 20~60px）、横排 ABCD 之间 |
| **V-DENY(iv)** | 切线穿过任何闭合矩形框或其内部内容 | 竖式框左边缘切进 `10.67−4.07=` 中间（现状） |
| **V-DENY(v)** | 缺口两侧属于同一 `number_path` 的同一辖区（需先按 B 系列算出编号归属，再做竖切判定） | 一道题的题干在左、作答位在右 |

> 判定顺序固定：**先定编号归属（B 系列）→ 再判能否竖切（V 系列）**。禁止反过来"先按 x 切分、再补编号"（现有 `_split_side_by_side_minors` 的做法，本案即由此判错）。

### 2.3 大题标题归谁

- 不单独成块。写 `major_title`（原文）+ `context` 首行。
- 像素归属：**只跟第一条小题**（`y_start=0`）。第二条起不带标题，避免同一标题在 N 条样本里重复出现。
- `subsection_title` 取 L2 编号行上的短标题原文（如 `直接写得数。（6分）`），**不重复进 `context` 正文**。
- 分值与题号一起保留原文（`（6分）` 不剥离），便于后续统计卷面。

### 2.4 三步判定顺序（v1.1 正式写死，禁止换序）

```
① D7 拦截（纯算式行 / 选项行剔除）
        ↓
② B 系列：定编号归属（哪一行是编号、编号属哪个作用域）
        ↓
③ V 系列：判竖切许可（这一列是不是一道独立的题）
```

- **顺序不可换。** 现状 `_split_side_by_side_minors` 是"先按 x 切、再补编号"，属于倒序，必须改。
- **① 必须在 ② 之前**：编号识别阶段就会把 `2.7+0.2=` 这类算式登记成疑似编号（D7-a），若等到 ② 之后才拦，边界序列已被污染（实测即如此）。
- **② 必须在 ③ 之前**：竖切许可的前提是"知道这一列属于哪道题"，不知道归属就没有"同一小题内部的并排"这个概念。

#### 2.4.1 两个阈值必须分离：「识别阈值」≠「许可阈值」

现状为修"三小问并排、`1.` 被 OCR 漏读导致整页吞并"的问题，在横向长条里把编号**识别**左限放开到块宽（`left_limit = crop_width`）。这与 V-B2 并不冲突，但两者必须写成两个独立的阈值，禁止互相借用：

| 阈值 | 用途 | 规则 | 放宽的后果 |
|---|---|---|---|
| **识别阈值**（`left_limit`） | **找**编号：允许编号出现在块中部 | 宽块（`h < 0.6w`）放开到块宽，**保留现状**，防止"三小问并排被整页吞并"的回退 | 只影响"能不能发现编号"，不影响"能不能切" |
| **许可阈值**（V-B1/V-B2） | **准不准竖切**：这一列是不是一道独立的题 | 编号须是**列首编号**（上沿 ≤ 列顶 + 0.25×列高）且左缘 ≤ 列宽 × 28% | 决定是否允许把这一列切开 |

**裁定（对 Q3）**：`识别放开 ≠ 许可放开`，按 V-B 优先。理由：放开左限是"识别"问题，V-B 是"竖切许可"问题；若以现状为准，本案会被误切，与 §0「版面空隙只有落在两个同层编号之间才允许当切线」直接矛盾。
同时补一条**硬约束**（由 D7-a 提供）：**识别阈值放开不得使纯算式行进入候选**——`2.7+0.2=` 在 x=809 处越限，本质是"算式被当编号"，不是"编号在中部"。D7-a 拦住它，识别阈值的放开才是安全的。

## 3. 跨栏 / 跨页 / 跨列

| # | 场景 | 归属规则 | 命名与字段 |
|---|---|---|---|
| **C1** | 同一页，一道题从左栏延续到右栏 | 归属主记录；延续部分**不新建样本** | `region_role='continuation'`，`continuation_of=<主记录 id>`，`number_path` 与主记录完全一致 |
| **C2** | 跨页延续（上一页末 → 下一页首），且下一页首块**带同一编号** | 命中 `(scope_id, number_path)` 去重 → 判 continuation | 同上；**不得**因"新页"而重置为 `question` |
| **C3** | 跨页延续，下一页首块**无编号** | 归属上一页最后一条 `question` 记录 | `continuation_of` 指向该记录；若上一页末条本身已是 continuation → 指向其根记录 |

## 4. 答案与解析的对应粒度

### 4.1 结论（对第 4 条的直接回答）

**一条样本 = 一个编号单元；该单元内多个作答位的答案，装进同一条样本的 `answer` 里，用「有序槽位列表」表达。**

即：`1. 直接写得数。（6分）` 的 8 个口算 → **1 条样本**，`answer` 为 8 个结果的有序列表，`answer_granularity='slot_list'`，每项带 `slot` 编号与定位。**不拆成 8 条样本。**

理由（三条，逐条对应甲方约束）：

1. **"一条样本一道题"**：8 个算式共用同一个编号 `1.` 与同一条指令 `直接写得数`，在卷面上就是**一道题**。拆成 8 条会产生 7 条没有编号、没有题干的样本 —— 既不能生成合法 `number_path`，也违反"题干文本必须完整"。
2. **"答案唯一"**：8 个空位的答案集合是**唯一确定**的（左手第 1 空 = 1.0，右手第 2 空 = 5.6 …），逐槽判分即可唯一判对错。"唯一答案"约束的是**歧义**，不是"单值"；有序槽位列表仍是唯一解。
3. **可判分性**：拆分后每条样本 `question` 只剩 `0.7+0.3=`，`knowledge_points`、`difficulty` 无法归属，解析也只能写成一句废话；合起来才是一条合格题目。

**允许拆分的唯一例外**（三条同时满足）：同一单元内 ≥2 个作答位，**且**各作答位有独立编号（`(1)(2)`/`①②`），**且**每个作答位有 ≥1 个完整句子或独立的作答空白框。此时按 §1.2 D1 走 L3 拆分，父级按 D2 处理。

### 4.2 槽位顺序（消除歧义，必须固定）

| # | 规则 |
|---|---|
| **A1** | 槽位顺序 = **栏优先**：先按栏（x 升序）分组，栏内按 y 升序。即两列四行口算 = 左列 1~4、右列 5~8。依据：与 `split_page_into_majors` 的"先左栏到底再进右栏"阅读顺序一致，全链路只有一种顺序。 |
| **A2** | 若答案页对同一小题的答案排版能判定顺序（答案也分栏/分行），**以答案页几何顺序为准**（同一排序函数作用在答案块上）；两侧顺序不一致 → `answer_order='unverified'` → **L2**。 |
| **A3** | 竖式计算：槽位 = 每个竖式一条，顺序按栏优先；`answer` 项内保存"竖式结果 + 竖式过程说明"，`analysis` 必需。 |
| **A4** | 答案页 `1. 2. 3.` 与题目侧一一对应：主键 `(match_scope_id, number_path)`；`major_number` 缺失时，在同 scope 内按"答案页大题序号 ↔ 题目页大题序号"顺序匹配，且匹配后必须校验编号序列连续，否则 L2。 |
| **A5** | 一个答案块内含多个小题答案（`1. 1.0 2. 5.6 3. …` 一长串）→ 按小题号把答案块切成子段；切不出子段 → `L2: answer_block_unsplit`，**不得**把整段塞给第一条样本。 |
| **A6** | 槽位数必须相等：`len(answer_slots) == len(question_slots)`。不等 → `L2: slot_count_mismatch`，**禁止**静默补空或截断。 |
| **A7** | `answer='略'`/`开放`/`言之有理即可` → `answer_type='open'`，必须带 `rubric`（评分口径）；无 rubric → **L2**。 |
| **A8** | `analysis` 粒度 = 样本粒度，不得为空；口算类允许逐槽解析（列表），但列表长度必须等于槽位数。 |

## 7. 验收口径（可被现有审计工具度量）

### 7.0 先定口径，再谈门限（v1.1 新增）

"多切了几道题"在现有数据上有 **6 种**合理算法，同一份审计集会给出 8 / 14 / 16 / 37 / 49 / 87 六个不同的数。**口径不写死，两个数字无法对话。** 因此 v1.1 把口径钉死：

| 口径 | 定义 | 60 页审计集实测（`reports/audit_baseline_v2_fixed.jsonl`，60 页 / 154 块 / 106 块有印刷题号） |
|---|---|---|
| **OC-1 块级·交付口径（主口径）** | 块内 `len(cut_numbers) − |set(printed_minors)|`，**仅在 `printed_minors` 非空的块上统计** | **Σ = 14**，过切块 **9** |
| **OC-2 页级·工具口径（交叉验证）** | 现有 `minor_extra`（切出集合 − 印刷集合） | **Σ = 16** |

> 说明：OC-1 的分母只算"块内确实印了题号"的块（106/154），与审计工具 L3 指标的统计口径一致；块内无印刷题号时无法判定"多切"，计入只会制造噪音。
