## 一、业务流程

```
标注员（本地工作台）
  └─ 框题 + 框答案 + 转文字
  └─ 提交审核：只传「审核用工程快照」+「这本教材用到的原书扫描页图」
        ↓
数据机 192.168.1.204（按账号私有归档 + 公共原书图片区）
        ↓
审核员（本地工作台）
  └─ 「审核 → 导入服务器工程」：选一个（可以是空的）本地目录
     → 自动下载原书图片 + 工程快照 → 直接看图、改框
  └─ 「回传修改到服务器」（带版本保护）
  └─ 逐页放行
        ↓
放行之后才允许生成甲方最终数据（K12 题库 JSONL + 裁图），并上传服务器
        ↓
老板（超级管理员）可看到所有人、所有教材、所有最终交付
```

关键：**甲方要求的最终 JSONL 在放行前不生成**；门禁在客户端和服务端各有一道。
**审核员不再需要找标注员要教材目录** —— 原书图片由提交流程自动带上。

## 二、改造内容

### 1. 服务器端 `online_review_beta/server.py`

| 改动 | 说明 |
|---|---|
| `GET /api/projects/<book_id>/snapshot` | 审核员/管理员下载**完整工程快照**（含题框）。按角色校验：标注员只能取自己的，审核员/管理员取本团队，超级管理员取全部 |
| `POST /api/projects/sync` 放开审核员 | 审核员/管理员可回传修改，但**必须带 `base_revision`**，与服务器版本不符返回 **409** |
| `_ensure_book_review_approved` 门禁 | 上传最终交付前强制校验全部页面 `approved`，否则拒绝（可 `PAPERFLOW_DELIVERY_REQUIRE_APPROVAL=0` 关闭） |
| `POST /api/projects/<book_id>/source-files` | 上传单张原书图片：校验相对路径/扩展名/48MB/SHA-256，写入 `Public\SourceImages\<教材编号>\` |
| `GET /api/projects/<book_id>/source-files` | 列出已存原图（含字节数，供客户端按尺寸跳过） |
| `GET /api/projects/<book_id>/source-file?path=` | 下载单张原图（按扩展名返回正确 MIME） |
| `ConflictError` | 新增异常类型，`do_POST` 映射为 HTTP 409 |

### 2. 客户端同步层 `review_tools/online_review_sync.py`

- `list_remote_projects` / `pull_project_snapshot` / `push_project_snapshot`
- `collect_project_source_images`：只收集工程**引用到的**页面原图，不整本拷贝
- `upload_project_source_images`：按尺寸比对跳过已传文件，支持中断后续传
- `fetch_project_source_images`：导入时按需下载到本地教材目录

### 3. 本地桥 `desktop_annotation/paperflow_annotation_api.py`

| 路由 | 作用 |
|---|---|
| `/api/review/list-projects` | 列出当前账号可见的服务器教材 |
| `/api/review/import-project` | **先下载原书图片**，再下载快照并按选定目录重定向图片根路径 → 落盘（自动备份同名旧工程）→ 可直接打开 |
| `/api/review/push-project` | 回传本地修改，冲突时给出明确提示 |
| `/api/review/upload-source-images` | 单独补传原书图片（首次提交失败时可重试，支持 `force`） |
| `_review_submit` | 提交快照成功后自动同步原书图片；图片同步失败不掩盖提交成功，转为提示 |
| `_sync_delivery` | 补门禁：存在未放行页面时拒绝生成最终交付 |

桥版本升至 `review-loop-source-images-20261021`（桥与 `electron/main.js` 两侧同步）。

## 六、已知局限与待办

1. **门禁返回 401 而非 403**：沿用本服务既有约定（`PermissionError` 统一映射 401），错误文案已明确说明「审核尚未全部放行」。
2. **原书图片按尺寸比对跳过**：服务器列表只返回字节数，不返回 SHA-256（避免列表请求去哈希整个教材）。尺寸一致的碰撞概率极低，且 `force=true` 可强制全量重传。
3. **单张原图上限 48MB**：超大扫描件会被拒并提示；如有需要可上调 `SOURCE_IMAGE_MAX_BYTES`。
4. **`question_detector.onnx` 模型未提交**（10.6MB → 11.5MB，属本次改造外的模型迭代），按你的要求保持不动，留在工作区。
5. 遗留待办：`paperflow-deploy` 账号降权（仍在 Administrators 组）、真实标注电脑 SMB 写入验证、数据机开关机自启验收、`J:\PaperFlowData` 定期备份任务。
