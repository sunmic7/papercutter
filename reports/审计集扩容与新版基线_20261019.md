# 审计集扩容与新版基线（2026-10-19）

## 1. 为什么扩容

旧审计集 6 本 21 页，在 P1 修完后**硬错误信号清零**（大题召回 45/45、有错页 0/9）。
这意味着一件事：任何后续改动都会得到"21 页一致"的结论——包括改错的改动。
规模不足的基线不是"干净"，是**没有分辨力**。

同时旧口径只会用 `--sample N` 抽页，而抽页依赖"文件名排序 + 步长"，
书目或代码一变就抽到另一批页（本项目中已因此白跑过一整轮）。

所以这一轮先做两件不改变切题行为的事：**扩样本**、**把页面清单固定下来**。

## 2. 数据集

- **20 本 / 60 页**，每本 3 页（跳过封面，取剩余页的 30% / 55% / 80%，避开书末答案区）
- 覆盖 6 种实际生效版式：exam 15、workbook 18、olympiad 9、instructional 6、holiday 6、drill 6
- 书目：`reports/audit_books_v2.txt`，页面清单：`reports/audit_plan_v2.jsonl`
- 生成脚本：`_experiments/build_audit_sample.py`（版式走生产口径 `detect_book_profile`，结论一并写进清单）

页面清单一旦固定，复跑就是同一批页。**60 页复跑实测 63 秒**（OCR 内容缓存全命中），
这才能支撑"改一处、立刻验一轮"的迭代节奏。

首次跑 60 页冷启动约 40 分钟（3 进程并行，单页 130~200 秒，大头是两条 OCR）。

### 中途停电

跑到 52/60 时断电，三个进程全部中断。因为每页写完立即落盘（`_audit_pending` 逐页 flush），
**52 页结果完整保留**；续跑只补了缺的 8 页，7 分钟完成，没有重算任何已完成的页。
这是"逐页落盘 + `_completed_paths` 跳过"设计第一次真正派上用场。

## 3. 审计口径的四处修正

新数据先暴露的是**指标本身的问题**，不是切题的问题。

| 信号 | 修正前 | 修正后 | 原因 |
|---|---|---|---|
| `untitled_with_evidence` | 18 | **4** | 练习册整页本来就没有"一、二、三"，只剩 1./2./3.，整页块是正常形态而非丢标题 |
| `continuation_blocks` 计入错页 | 是 | **否** | 块无标题但题号从中间续上，是大题跨栏/跨页的正常形态；计入后整批两栏页全红 |
| `giant_cuts` | 20 | **1** | 原判据"单框 > 50% 页高"在"印刷 2 题、也切出 2 题"时照样触发，长题干/带图题被当成吞并 |
| `seq_breaks` | 5 | **0** | 两栏页每栏都从 1 开始，切出 1,2,1,2 与印刷完全一致；只有题号集合不一致时"回头"才算错 |

修正后**错页从 38 降到 17**（适用 48 页）。换句话说，旧口径里一半以上的"错误"是量表噪声。

另外新增两个**直接与真值比对**的一等指标，替代几何启发式：

- `minor_missed`：块内印刷了题号、但没被切出来的个数（漏切）
- `minor_extra`：切出来的题号印刷上没有的个数（多切 / 题号误读）
- `minor_recall = 1 - 漏切 / 印刷`

## 5. 三个结论

### 5.1 P2-3（对开页拆两个逻辑页）的前提不成立

12 张宽高比 ≥1.24 的对开页，**全部**识别为 `columns=2`，块标签 `left/right` 全部正确（32 左 / 22 右），
没有出现路线图预估的"左页单栏 + 右页双栏 = 3 栏"，也没有出现 `column_N` 标签污染跨页续题语义。

也就是说这条排期在最深改动位置上的收益，在这批真实数据上是 **0**。
不做，省下的时间放在 5.3。

### 5.2 真正的主战场是"小题漏切"，不是栏位

漏切 27 题里，最典型的形态是：**块内印刷 1、2、3，只切出 3**（前两题被吞进块首）。
这是 L3 层的问题，和栏位、版式判定都无关。

### 5.3 drill / holiday 的"低分"有一半是量表的锅

- **drill 5 页**：右栏"3. 应用题"下面用 `(1)(2)` 编号，而审计真值只认 `1.` `2.`。
  切题侧在 `(1)` 处切分是**对的**，量表的印刷题号集合里却没有 `(1)`，于是记成"漏了 3."。
- **holiday 一页**：真漏——右栏"二、根据汉语完成英语句子"下的 1./2./3. 确实没切出来。

结论：`printed_minor_numbers` 需要把 `(1)` `（1）` 也算作印刷题号，
否则 drill 这类"大题套 (1)(2) 子题"的书会长期被低估 1/3。

## 6. 下一步

1. **修真值口径**：`(1)`/`（1）` 计入印刷题号，重跑 60 页（1 分钟），得到没有口径污染的小题召回。
2. **修漏切**：只针对"块内印刷 ≥2、切出 < 印刷"的 22 个块，先看 3 个代表页的题号坐标，
   判断是左侧位置限制（`left_limit`）还是间距判据拒绝，改一处、全量复跑验证。
3. P2-3 从排期移除；虚线栏缝仍然保留（`image0002586A` 那类页在本批里没再出现，样本不足以下结论）。

## 7. 复现方式

```bash
# 生成/校验固定清单（版式按生产口径判定）
python _experiments/build_audit_sample.py reports/audit_books_v2.txt reports/audit_plan_v2.jsonl --per-book 3

# 全量跑（60 页，冷启动约 40 分钟；有 OCR 缓存时约 1 分钟）
python review_tools/cut_quality_audit.py --pages-from reports/audit_plan_v2.jsonl --out reports/audit_baseline_v2_fixed.jsonl

# 按版式汇总（大题召回 / 小题召回 / 漏切 / 错页）
python _experiments/summarize_profiles.py reports/audit_baseline_v2_fixed.jsonl
```

并行跑分片时，各分片写自己的 JSONL，再用
`python _experiments/merge_shards.py reports/audit_plan_v2.jsonl <输出> reports/audit_v2_s*.jsonl` 合并。
